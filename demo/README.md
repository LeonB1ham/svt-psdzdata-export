# Demo

Sample SVT plus a tiny fake PSdZData. No real BMW firmware.

```bat
.\demo\run-demo.ps1
```

Output goes to `demo/out/`. Reference manifest: `export-example/svt_export_manifest.txt`.

GUI:

```bat
py -3 app.py --demo
```

Window screenshots: `screenshots/01-start.png`, `02-results.png`, `03-selection.png`.
